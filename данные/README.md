# Данные для независимой проверки результатов

Обезличенная выгрузка к статье «Индивидуальные ценности как предиктор выбора стратегий убеждения в парных деловых переговорах». Файлы позволяют воспроизвести все опубликованные оценки, не обращаясь к исходным записям переговоров.

## Файлы

| Файл | Строк | Что это |
|---|---|---|
| `participants.csv` | 123 | участники: когорта, пол, возраст, ценностные баллы |
| `performances.csv` | 244 | выступления: условия и применённые стратегии |
| `build_public_dataset.py` | — | скрипт сборки выгрузки из исходных данных |

Ценностные баллы заполнены у 107 участников из 123 (`has_values = 1`); остальные 16 в поединках участвовали, но опросник не заполняли и в анализ связи с ценностями не входят.

## `participants.csv`

| Колонка | Описание |
|---|---|
| `participant_id` | псевдоним (`P001`…`P123`) |
| `cohort` | 1, 2 или 3 — этап сбора |
| `collection_period` | `2025-10`, `2026-02`, `2026-03` |
| `sex` | `Ж` / `М` |
| `age` | полных лет на момент сбора |
| `has_values` | заполнен ли опросник ценностей |
| `MRAT` | средний балл респондента по всем 19 пунктам |
| `SDT`, `SDA`, `ST`, `HE`, `AC`, `FOR`, `POD`, `FAC`, `SES`, `SEP`, `COR`, `COI`, `TR`, `IIUM`, `BED`, `BEC`, `UNC`, `UNN`, `UNT` | 19 уточнённых ценностей, сырые баллы |
| `Self-Direction` … `Universalism` | 12 шкал среднего уровня, сырые баллы. Это десять широких ценностей Шварца, к которым добавлены репутация (`Face`) и скромность (`Humility`) как самостоятельные — см. раздел «Методы» статьи |
| `Self-Transcendence`, `Self-Enhancement`, `Openness-to-Change`, `Conservation` | 4 ценности высшего порядка, сырые баллы |

**Центрирование.** Все баллы даны сырыми. Центрированный балл, используемый в статье, получается вычитанием `MRAT`: `c_X = X − MRAT`. Для разностей двух ценностей (например, «сохранение − открытость») центрирование роли не играет: `MRAT` сокращается.

## `performances.csv`

| Колонка | Описание |
|---|---|
| `performance_id` | псевдоним выступления (`S001`…`S244`) |
| `participant_id` | ссылка на участника |
| `cohort` | этап сбора |
| `case` | версия кейса: `A` (когорты 1 и 2) или `B` (когорта 3) |
| `duel` | псевдоним поединка; два выступления с одним `duel` — это пара соперников |
| `role_slot` | `slot_1`, `slot_2`, `slot_3` — какую из трёх ролей играл участник |
| `player` | 1 или 2 — порядок выбора роли |
| `attempt` | 1 или 2 — первый или второй поединок участника |
| `prompted_strategy` | стратегия, под которую промптирована роль |
| `turns` | число ходов (реплик) участника в выступлении |
| `n_principles_used` | сколько разных принципов из семи применено |
| `used_<принцип>` | 1, если принцип применён хотя бы раз |
| `turns_with_<принцип>` | число ходов, в которых принцип размечен |
| `markers_<принцип>` | число маркеров (цитат-подтверждений) принципа |

Семь принципов: `authority`, `commitment`, `liking`, `reciprocity`, `scarcity`, `social_proof`, `unity`.

⚠️ **Не перепутайте `turns_with_` и `markers_`.** Доля ходов со стратегией, на которой построены проверки устойчивости в статье, — это `turns_with_X / turns`, а не `markers_X / turns`. В одном ходе может быть несколько маркеров одного принципа.

**Привязка ролей к стратегиям различается между версиями кейса.** В версии A под авторитет промптирован `slot_1`, под обязательство `slot_2`; в версии B они поменяны местами. `slot_3` в обеих версиях промптирован под социальное доказательство. Проверяется одной строкой:

```python
pd.crosstab([S['case'], S.role_slot], S.prompted_strategy)
```

Сама привязка следует из формулировок ролевых инструкций; соответствие технических кодов ролей персонажам версии B восстановлено по совпадению интересов, без отдельного документа-легенды. Косвенная проверка на этих же данных её подтверждает: в когорте 3 авторитет применяется в 95 % выступлений в приписанной ему роли против 65 % в остальных. Подробнее — раздел «Ограничения» статьи.

## Что в выгрузку не входит

Исключены прямые идентификаторы и данные, из которых участник опознаётся по содержанию:

- фамилии и имена участников;
- тексты реплик и цитаты-маркеры из разметки — они содержат названия компаний, продуктов, проектов и имена коллег;
- названия компаний-работодателей участников и конкретных программ обучения (площадка сбора — Московская школа управления «Сколково» — одна для всех трёх когорт и названа в статье).

Когорты обозначены только номером и месяцем сбора. Сочетание «когорта + пол + возраст» в ряде случаев единственно в своей когорте, поэтому участник, присутствовавший на той же сессии, теоретически может опознать коллегу; для внешнего исследователя, не знающего состава групп, такое сопоставление невозможно. Публикуемые переменные не относятся к специальным категориям персональных данных.

Соответствие «псевдоним → исходный идентификатор» хранится авторами отдельно и не публикуется.

## Воспроизведение ключевых оценок

Проверено: приведённый ниже код даёт числа, опубликованные в статье.

```python
import pandas as pd, numpy as np
import statsmodels.api as sm, statsmodels.formula.api as smf
from scipy import stats

P = pd.read_csv('participants.csv')
S = pd.read_csv('performances.csv')
v  = P[P.has_values == 1]
sv = S[S.participant_id.isin(v.participant_id)]
d  = sv.merge(v.drop(columns=['cohort']), on='participant_id')

# Самостоятельность → взаимный обмен: OR 0,59 [0,44; 0,80], p < 0,001
d['x'] = (lambda s: (s - s.mean()) / s.std())(d['Self-Direction'] - d['MRAT'])
d['y'] = d['used_reciprocity']
m = smf.gee('y ~ x + C(cohort)', groups='participant_id', data=d,
            family=sm.families.Binomial()).fit()
print(np.exp(m.params['x']), np.exp(m.conf_int().loc['x']).values, m.pvalues['x'])

# Разность приоритетов «сохранение − открытость» и доля апелляций к отношениям: r = 0,32, p < 0,001
norm = sv.groupby('participant_id').apply(
    lambda x: ((x.turns_with_reciprocity / x.turns).mean()
             + (x.turns_with_liking     / x.turns).mean()) / 2).rename('norm').reset_index()
pl = norm.merge(v, on='participant_id')
print(stats.pearsonr(pl['Conservation'] - pl['Openness-to-Change'], pl.norm))
```

Воспроизводятся также: характеристика выборки (таблица 1 статьи), частоты применения стратегий, связь репутации с авторитетом на подвыборке, где стратегия не предписана ролью (отношение шансов 1,65, p = 0,012) и проверка манипуляции (авторитет в своей роли против чужих).

## Пересборка выгрузки

Скрипт запускается из рабочего каталога исследования, где лежит закрытый пайплайн разметки. В настоящем репозитории он приведён как свидетельство происхождения данных и самостоятельно не запускается:

```bash
python3 данные_для_проверки/build_public_dataset.py --key /путь/вне/репозитория/ключ.csv
```

Скрипт строит панель тем же кодом, что и анализ в статье (`h2/build_panel.py`), поэтому выгрузка и опубликованные оценки не могут разойтись. Псевдонимы присваиваются детерминированно, повторный запуск даёт те же номера.
