# Индивидуальные ценности как предиктор выбора стратегий убеждения в парных деловых переговорах

Материалы статьи, подготовленной для журнала «Вестник евразийской науки» (специальность ВАК 5.2.6 «Менеджмент», экономические науки).

**Авторы.** Запылихин В.С., Диденко А.С.

**Кратко.** На материале 1378 размеченных реплик из 244 переговорных выступлений проверяется, связан ли выбор приёмов убеждения по Р. Чалдини с индивидуальными ценностями по модели Ш. Шварца. Ценности измерены опросником PVQ-RR до начала переговоров у 107 участников. Основной результат: значимые связи концентрируются вдоль оси «сохранение — открытость изменениям».

## Данные для проверки

В каталоге `данные/` лежит обезличенная выгрузка, по которой воспроизводятся все опубликованные оценки: `participants.csv` (123 участника, ценностные баллы у 107 из них) и `performances.csv` (244 выступления с показателями применения стратегий). Словарь переменных и готовый код воспроизведения — в `данные/README.md`.

Из выгрузки исключены фамилии участников, тексты реплик и названия компаний-работодателей. Соответствие псевдонимов исходным записям хранится у авторов и не публикуется.

## Требования журнала, по которым собран текст

Объём основного текста 12 000–40 000 знаков с пробелами без метаданных и списка литературы. Аннотация 180–230 слов без аббревиатур. Семь ключевых слов. Не менее 15 источников по ГОСТ Р 7.0.100–2018, пронумерованных по порядку упоминания, у каждого DOI, EDN или URL. В список литературы допускаются только статьи в научных журналах, статьи в сборниках конференций, книги и монографии; интернет-ресурсы, препринты, стандарты и диссертации оформляются постраничными сносками. Структура IMRaD, название основной части отличается от названия статьи.

## Оговорка о статусе результатов

Три из четырёх связей, обсуждаемых в статье, выделены разведочным перебором 245 моделей и обозначены как поисковые. Статус проверенной гипотезы имеет только связь по оси «сохранение — открытость изменениям», сформулированная до обращения к данным. Это указано в тексте и не должно теряться при пересказе результатов.
